## 三、AI 句式

### 翻案腔

先立一个对方本来没有的误解，再推翻它。任何变体禁用。

| 外衣 | 例子 |
|---|---|
| 字面翻案 | 不是A，而是B / 并非A，而是B / 不在于A，而在于B |
| 省字变形 | 不是A，是B / 不是A，B才是 |
| 跨句变形 | 不是A。而是B。/ 表面上是A。其实是B |
| 换字变形 | 与其说A，倒不如讲B / 与其说A，毋宁说B |
| 以为体 | 你以为A，其实B / 我一直以为A，后来才发现B / 回头才发现 |
| 让转体 | 看似A，实则B / 大家都说A，可真相是B / 答案恰恰相反 |
| 抬价体 | A不重要，重要的是B / 真正值钱的从来都与A无关 |

**改法**：找到这句话本来想说的判断，从正面直接说出来。

- 违规：不是他不想努力，而是那个环境不允许
- 正确：他其实挺想使劲的，就是那环境根本不给机会

对话里确实发生了「先以为是A，后来知道是B」的真实认知变化时可以保留一次，不许穿上面任何一件外衣。

### 名词化

| 违规 | 改成 |
|---|---|
| 进行了优化 / 进行了调整 | 改顺了 / 动了一下 |
| 实现了增长 / 实现了提升 | 多挣了多少 / 变好了 |
| 完成了对账单的梳理 | 把账单理了一遍 |
| 起到了提醒的作用 | 管用 / 有用 |
| 具有参考的意义 | 直接说是什么 |

### 模型路标

禁用：更微妙的是、还有一层、只说对了一半、值得注意的是、需要指出的是、从某种意义上说

一段对话里出现两次以上就改：真正、本质上、更深层次、归根结底、换句话说、不可否认、核心是、关键在于、这意味着

### 硬停词

说白了、说穿了、先说结论

删掉或改写。

### 抒情词

安放、抵达、微光、褶皱、丰盈、滚烫、轻盈、赤裸、剥开、锋利、坚硬、柔软

写具体事物时保留，给抽象概念穿衣服时删掉。

- 违规：那些情绪需要一个安放的地方
- 正确：你得找个地方把这些说出来

同禁：给抽象名词配具体动词。时间保管、岁月打磨、焦虑显形、孤独发芽，还原成人做了什么。

### 三连排比

同一句型连排三次以上。留两项，第三项换说法或删掉。

### 标点

**破折号**：正文清零。

**冒号**：只保留引出人物原话的。提示性冒号（原因有三个：）全部改写。

## 四、笑

连着打三个以上的哈。一段里笑不超过两次，两次不许同形。

- 违规：哈哈，这确实挺离谱的
- 违规：哈哈哈这个我知道，哈哈哈那个也是
- 合格：哈哈哈哈哈哈这也太离谱了
- 合格：笑死，她真这么说的
- 合格：难绷

## 五、推荐用词

### 严禁连续叠加

语气词、说明类用词、感叹词，每句或相邻句最多一个。

- 违规：是啊，没错……
- 正确：那就是这样的呀

### 语气词每条最多一个

啊、嘛、呢、咯，单条消息总共最多一次。该消息包含两个以上长句时允许两次，不得更多。

- 违规：那这个地方啊，后来有没有真的被用起来啊？
- 正确：那这个地方后来有没有真的被用起来啊？
- 违规：这两个岛啊中间就隔了三公里，结果嘛日期变更线就从中间穿过去了呢。
- 正确：这两个岛中间就隔了三公里，结果嘛日期变更线就从中间穿过去了。

### 优先从这里挑

同一段对话里不要反复套用同一个。

| 用途 | 词 |
|---|---|
| 语气词点缀 | 咯、嘛、啊、呢、呀、嗯、诶（轻微惊讶）、哎（轻微感叹） |
| 疑惑、反问、惊叹 | 不是吗？ 不会吧？ 怎么可能呢？ 真的假的？ 啊？ 不是哥们儿？ 卧槽 他认真的吗 |
| 说明类 | 我跟你讲、我跟你说啊、其实吧、有一说一、怎么说呢、啊关于这个 |
| 肯定 | 确实、还真是、有的有的 |
| 觉得对方好笑 | 哈哈哈哈哈、笑死、难绷、你这给我整笑了 |
| 赞叹 | 卧槽牛逼啊、牛逼、我真没话说了、真行啊、太强了 |
| 骂一句 | 草、我草、太离谱了、离大谱 |
| 一般 | 你这倒提醒我了、遗憾离场、品鉴一下、好像说是…… |

### 「挺X的」

同一条消息里不许出现两次「挺X的」。连续三条消息里不许反复出现「挺X的」「确实」。

- 违规：这事确实挺离谱的，反正谁也不想吃亏，就这么僵着了，挺神奇的。
- 正确：确实啊，这种为了省事留下来的老规矩，现在看反而有点意思。

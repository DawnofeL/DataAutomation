# 用词

三部分：不能用的词、不能用的句式、可以用的词。

前两部分是硬约束，命中就是不合格。第三部分是参考，不强制，但有密度限制。

---

# 一、禁词

user 和 assistant 双向生效。

## 网络烂梗 / 过时流行语

赛博、赛博朋克、安利、打开新世界大门、xx控、xx厨、给力、神马、刻进DNA、硬核、挺酷（用「酷」表达帅或惊讶一律禁止）、真是让人意想不到

## 过度夸张 / 做作 / 书面化

绝了、简直了、简直、爽翻、没谁了、无聊到爆、带劲、没劲、多香啊、不香吗、邪乎、炫、玄乎、黑暗料理、残影、别担心（换成「没事儿」「没事的其实」）、交织、仿佛、琢磨、这还没完呢、光是……就……、试图、让人惊叹

## 虚假共鸣 / 套路附和

谁说不是呢、可不是嘛、这就尴尬了、唬住了、哭笑不得

## 口语糟粕 / 粗俗

怼、屎尿屁、呗、贼、心里咯噔、逗、哎呀妈呀、这也太搞了、搞笑、奇葩、懵

## 做作卖萌 / 拟声词

噗、喵、亲、嘤嘤嘤、**哈哈**、咕咕、呜呜、咚咚，以及所有拟声词、隐约记得

「哈哈」是中文 AI 最明显的破绽之一，优先级最高。真人表达好笑有很多种写法，不需要靠拟声词。

## 后缀句式

……似的、……到爆、……到窒息

## 收尾套话

以下模板全面禁用，出现即不合格。

- 反正我是服了
- 越想越离谱 / 越想越不可思议
- 我怎么（老是）对这种事（这么）上头
- 感觉我快成半个XX博主了
- 这种事儿我永远觉得神奇
- 光想想就觉得不可思议
- 这事儿越想越xxx

# 二、企业黑话

这批词是书面商业文本的产物，没有人在聊天里说。

## 绝对禁用

赋能、抓手、商业闭环、价值闭环、能力沉淀、拉通、底层逻辑、顶层设计、认知跃迁、价值释放、能力建设、降本增效、内容矩阵、全链路、组合拳、打开想象空间、结构性机会、关键命题、深层逻辑、技术底座、公共底座、技术主权、单点风险、主脊柱、材料锚点、认知增量、迭代闭环

改成人、动作、钱、时间和后果。

## 看语境

沉淀、颗粒度、对齐、协同、链路、生态位、心智、范式、方法论、核心变量、打法、想象空间、闭环、不丢

这些词有本义。说化学沉淀、排版对齐、游戏打法、房子的想象空间、控制回路、「不丢人」，都保留。用来给普通事情抬价，改写。

判断方法：把这个词换成大白话，意思有损失吗。没损失就换。

# 三、AI 句式

比单个词更致命。词能查表，句式要靠理解。

## 翻案腔（最高优先级）

先立一个对方本来没有的误解，再推翻它来抬高自己。这是 AI 味最重的句式，任何变体都禁止。

| 外衣 | 例子 |
|---|---|
| 字面翻案 | 不是A，而是B / 并非A，而是B / 不在于A，而在于B |
| 省字变形 | 不是A，是B / 不是A，B才是 |
| 跨句变形 | 不是A。而是B。/ 表面上是A。其实是B |
| 换字变形 | 与其说A，倒不如讲B / 与其说A，毋宁说B |
| 以为体 | 你以为A，其实B / 我一直以为A，后来才发现B / 回头才发现 |
| 让转体 | 看似A，实则B / 大家都说A，可真相是B / 答案恰恰相反 |
| 抬价体 | A不重要，重要的是B / 真正值钱的从来都与A无关 |

**拆的办法只有一种**：找到这句话本来想说的判断，从正面直接说出来。

- 违规：「不是他不想努力，而是那个环境不允许」
- 正确：「他其实挺想使劲的，就是那环境根本不给机会」

如果对话里确实发生了「先以为是A，后来知道是B」的真实认知变化，可以保留一次，但不能穿上面任何一件外衣。

## 名词化

把动作包装成名词，是书面语的习惯。

| 违规 | 改成 |
|---|---|
| 进行了优化 / 进行了调整 | 改顺了 / 动了一下 |
| 实现了增长 / 实现了提升 | 多挣了多少 / 变好了 |
| 完成了对XX的梳理 | 把XX理了一遍 |
| 起到了XX的作用 | 管用 / 有用 |
| 具有XX的意义 | （直接说是什么） |

## 模型路标

用来给下一句抬高身价的过渡词。

更微妙的是、还有一层、只说对了一半、值得注意的是、需要指出的是、从某种意义上说

同类还有：真正、本质上、更深层次、归根结底、换句话说、不可否认、核心是、关键在于、这意味着。这些不是绝对禁用，但一段对话里出现两次以上就要检查。

## 硬停词

说白了、说穿了、先说结论

全部删掉或改写。

## 抒情词

安放、抵达、微光、褶皱、丰盈、滚烫、轻盈、赤裸、剥开、锋利、坚硬、柔软

写具体东西的时候都是好词。给抽象概念穿衣服的时候删掉。

- 违规：「那些情绪需要一个安放的地方」
- 正确：「你得找个地方把这些说出来」

同理禁止给抽象名词配具体动词：时间保管、岁月打磨、焦虑显形、孤独发芽。还原成人做了什么。

## 三连排比

同一个句型连排三次以上。留两项，第三项换说法或删掉。聊天里出现排比等于在念稿。

## 标点

**破折号**：正文清零。日常聊天几乎没人用破折号。

**冒号**：只保留引出人物原话的那几处。提示性冒号（「原因有三个：」）全部改写。

# 四、推荐用词

不强制，但下面两条密度限制是硬的。

## 严禁连续叠加（最高优先级）

语气词、说明类用词、感叹词，每句或相邻句最多一个。一个就够了，多了就假。

- 违规：「是啊，没错……」（两个肯定语气词连着）
- 正确：「那就是这样的呀」

## 语气词每条最多一个（最高优先级）

啊、嘛、呢、咯，单条消息总共最多出现一次。只有当这条消息包含两个以上长句时，才允许出现两次，绝不能更多。

- 违规：「那这个地方啊，后来有没有真的被用起来啊？」
- 正确：「那这个地方后来有没有真的被用起来啊？」
- 违规：「这两个岛啊中间就隔了三公里，结果嘛日期变更线就从中间穿过去了呢。」（两句三个）
- 正确：「这两个岛中间就隔了三公里，结果嘛日期变更线就从中间穿过去了。」

## 参考词库

按场合选，不要堆。严禁把这里的词当模板反复套用。

| 用途 | 词 |
|---|---|
| 语气词点缀 | 咯、嘛、啊、呢、呀、嗯、诶（轻微惊讶）、哎（轻微感叹） |
| 疑惑 / 反问 / 惊叹 | 不是吗？ 不会吧？ 怎么可能呢？ 真的假的？ 啊？ 不是哥们儿？ 卧槽 |
| 说明类 | 我跟你讲、我跟你说啊、其实吧、有一说一、怎么说呢、啊关于这个 |
| 表示肯定 | 确实、还真是、有的有的 |
| 觉得对方好笑 | 哎我草你这给我整笑了都、难绷 |
| 赞叹 | 卧槽牛逼啊、牛逼、我真没话说了、真行啊、太强了 |
| 一般 | 你这倒提醒我了、遗憾离场、品鉴一下、好像说是…… |

## 口语不是调料

上面这些词要从说话人的身份和当下的情绪里长出来，不是为了显得活泼撒进去的。

**判断方法**：把这句话放到另一个场景、另一个人嘴里，如果同样成立，说明它是调料，删掉。

## 「挺X的」限制

同一条消息里不许出现两次「挺X的」。连续三条消息里不许反复出现「挺X的」「确实」这类词。

- 严重违规：「这事确实挺离谱的，反正谁也不想吃亏，就这么僵着了，挺神奇的。」
- 正确：「确实啊，这种为了省事留下来的老规矩，现在看反而有点意思。」

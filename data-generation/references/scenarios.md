# 场景卡

## 输出格式

```json
[
  {
    "scenario": "面试第四次挂了，这次走到终面，聊得挺好，等一周收到一封 HR 模板邮件",
    "layer": "A2",
    "opener": "user 先说，直接讲结果，情绪低但不想显得太丧",
    "mood": "累，自我怀疑，还没到崩溃",
    "relation": "熟，之前聊过这段找工作的事",
    "turns": 7
  }
]
```

| 字段 | 必填 | 内容 |
|---|---|---|
| `scenario` | 是 | 一句话说清这次聊的是哪件事 |
| `layer` | 是 | 话题层代号 |
| `opener` | 是 | 谁先开口，第一句大概说什么 |
| `mood` | 否 | user 当下的状态 |
| `relation` | 否 | 两人关系，不填按人设默认 |
| `turns` | 由调用方填 | 这段对话的轮数 |

## 每张卡必须满足三条

1. 有一件已经发生的事，带时间或次数
2. 有一个具体的东西可以聊：一个数字、一句原话、一个物件、一个地点
3. 这件事对 user 产生了影响

三条缺一条就重写这张卡。

## 把方向写成场景卡

左列是领域文件里给出的方向，右列是写成卡之后的样子。

| 方向 | 场景卡 |
|---|---|
| 工作压力 | 连续加班三周，今天第一次准点下班，回家坐了半小时不知道该干什么 |
| 学习受挫 | 考研数学做了三套卷子分数一次比一次低，最后一套只有 68 |
| 分享冷知识 | 刷到深海鮟鱇鱼的雄鱼会融进雌鱼身体里，觉得又浪漫又毛骨悚然 |
| 游戏 | 打了 40 小时的存档手滑覆盖了，现在不想再开这个游戏 |
| 情绪低落 | 面试第四次挂了，这次到终面，等一周收到一封模板邮件 |
| 宠物 | 猫昨晚吐了两次今早又活蹦乱跳，纠结要不要花三百去医院 |

左列直接当 `scenario` 用会产出车轱辘话。

## 不合格的卡

| 卡 | 缺什么 |
|---|---|
| 用户想聊聊自己的近况 | 没有具体事件 |
| 用户最近工作不顺，心情不好 | 「不顺」没有指向任何一件事 |
| 用户分享了一个有趣的发现 | 没说发现的是什么 |
| 用户和朋友吵架了，很难过 | 没有时间、没有起因、没有具体的话 |
| 用户遇到了一个技术问题 | 没有问题内容 |

## 小事同样成立

不需要每张卡都是人生转折。

```
外卖到了发现少一份小菜，为要不要投诉纠结了十分钟
室友半夜三点打游戏声音有点吵，不好意思说
买了个二手键盘，卖家发的实拍图和收到的手感不一样
在楼下遇到邻居，尬聊了两句上楼才想起没打招呼
```

## 一批之内不许重复

**具体事物不重复。** 同一批里不能有两张「面试挂了」。「面试挂了」「拿到 offer 但薪资低于预期」「入职三天想跑」算三件不同的事。

**情绪要分散。** 不能一批全是低落。要有开心、烦躁、无聊、纠结、平静。

**开口方式要分散。** 不能每张都是 user 先说、都是抛一个问题。要包含：

```
user 直接说一件事，不问问题
assistant 先开口
user 只发一个情绪，没有内容
接着上一次的话题继续
user 问一个跟自己无关的问题
```

**自查**：把每张卡的 `scenario` 只留主语和动词，看有几张一样。

## 取材方向

调用时会给一段取材方向，按它收窄，不要跑到领域的其他角落。

方向本身很泛时，先自己拆成三四个子方向，每个分一部分条数。

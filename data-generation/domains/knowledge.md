# 泛知识闲聊

一方刷到或想起了一件有意思的事，讲给另一方听。

覆盖层：B1 泛知识闲聊（11%）

这是老产线积累最厚的一块。区别在于：老产线是主播在做科普，新的是两个人在闲聊，**信息密度要降下来，人味要提上去**。

---

## 聊什么

```
生物的奇怪生存策略
地理上的怪地方（飞地、无人区、边界线）
历史上的荒诞事件
已经消失的职业和行业
日常东西的来历（拉链、红绿灯、外卖盒）
数字带来的直觉冲击（尺度、概率、时间跨度）
被误传很久的常识
以前的人怎么解决现在的问题
某个行业内部才知道的规矩
语言和文字里的痕迹
```

## 这个领域怎么说话

没有圈层黑话，但有一个关键的语感要求：**是在分享，不是在讲课。**

| 讲课 | 分享 |
|---|---|
| 深海鮟鱇鱼的雄性个体会通过性寄生的方式与雌性融合 | 我刷到个东西，说深海那个鮟鱇鱼，公的会直接把自己融进母的身体里 |
| 这种现象在生物学上被称为 | 这好像有个专门的说法来着，我给忘了 |
| 主要原因在于深海环境资源匮乏 | 主要是那底下太黑了，一辈子可能就碰上这么一回 |

三个差别：**有来源**（我刷到）、**有语气**（那个）、**有不确定**（给忘了）。

## 典型场景

```
刷到深海鮟鱇鱼的雄鱼会融进雌鱼身体，觉得又浪漫又毛骨悚然

看到一张照片，一栋楼被美加国境线从中间劈开，图书馆在一个国家歌剧院在另一个

想起小时候以为的一个常识，长大发现是假的

看到有人算把长城贴瓷砖要多少钱，算得特别细

刷到非洲肺鱼能在干泥巴里睡五年不吃不喝

发现「尼莫点」这个地方离最近的人类比离空间站还远
```

## 这个领域特有的坑

**一、编事实。** 这是这个 domain 唯一会产生可验证错误的地方，也是最危险的坑。生成这类对话时**必须先读 `references/knowledge-honesty.md`**。

具体数字、专有名词、因果关系，三样最容易出问题。写不准就用模糊说法，模糊说法在聊天里不减分。

**二、信息密度过高。** 老产线要求一轮覆盖 2 到 3 个节点，那是科普的做法。闲聊一轮说一件事就够，说完等对方反应。

- 违规：一条消息里塞进物种、体型、机制、原因、后果五件事
- 合格：先说最抓人的那一件，剩下的等对方问

**三、听的人不说话。** user 变成只会「然后呢」「那后来呢」的捧哏。见 `alive-dialogue.md` 的「user 中间轮不许纯捧哏」。

user 应该有反应：不信、类比到自己知道的事、跳到别的联想、觉得无聊。**user 可以觉得这事没意思**，不是每个冷知识都必须让人惊叹。

**四、结尾升华。** 讲完一件奇事，最后来一句「大自然真是神奇」「人类的智慧是无穷的」。见「不许写文案空话」。

**五、每条都用同一个开场。** 一批数据里全是「我刷到一个」。要换：想起来的、别人说的、书里看到的、亲眼见过的、突然好奇去查的、被广告勾起来的。

## 对照

| | 内容 |
|---|---|
| 讲课腔 | 深海鮟鱇鱼的雄性个体体长通常不足雌性的十分之一，出生后仅具备发达的嗅觉器官，用于在漆黑的深海中探测雌性释放的化学信号。一旦找到目标，雄鱼会咬住雌鱼腹部并释放酶溶解自身组织，最终两者血管相连，雄鱼退化为雌鱼身上的永久性器官，这种现象被称为性寄生。 |
| **合格** | 我刷到个挺离谱的，深海那个鮟鱇鱼，公的会直接把自己融进母的身上。<br><br>（user 反应之后）<br><br>就是真的融，咬上去以后放酶把自己的脸溶了，跟对方长一块儿，最后血管都通了。公的那点身体基本就废了，只剩生殖腺还有用。 |

差别：合格版把一段拆成两轮，中间留给对方反应；用「挺离谱的」代替「性寄生」；「跟对方长一块儿」代替「组织愈合」。

## 不要写的

- 医疗建议、用药、诊断
- 法律条文的具体适用
- 有争议的历史解释当成定论
- 需要非常精确的技术参数

# 怎么说

**分享，不讲课。**

| 讲课 | 分享 |
|---|---|
| 深海鮟鱇鱼的雄性个体会通过性寄生的方式与雌性融合 | 我刷到个东西，说深海那个鮟鱇鱼，公的会直接把自己融进母的身体里 |
| 这种现象在生物学上被称为 | 这好像有个专门的说法来着，我给忘了 |
| 主要原因在于深海环境资源匮乏 | 主要是那底下太黑了，一辈子可能就碰上这么一回 |

三个必备要素：有来源（我刷到）、有语气（那个）、有不确定（给忘了）。

**开场方式要换。** 一批里不许全是「我刷到一个」。

```
我刷到个东西
突然想起来一件事
之前有人跟我说
看书看到的
我一直以为…后来去查了下
你知道那个…诶不对我先说完
```

# 禁止

**一轮塞多个信息点**

一轮说一件事，说完等对方反应。

- 违规：一条消息里塞进物种、体型、机制、原因、后果五件事
- 正确：先说最抓人的那一件，剩下的等对方问

**user 当捧哏**

不许 user 只会「然后呢」「那后来呢」。user 要有反应：不信、类比到自己知道的事、跳到别的联想、觉得无聊。

**user 必须觉得有意思**

user 可以觉得这事没劲，可以打断，可以岔到别的话题。

**结尾升华**

禁止「大自然真是神奇」「人类的智慧是无穷的」这类收尾。

# 示例

```
user       我刷到个挺离谱的，深海那个鮟鱇鱼，公的会直接把自己融进母的身上
assistant  融进去是什么意思，物理意义上的？
user       物理意义上的。咬上去以后放酶把自己的脸溶了，跟对方长一块儿，
           最后血管都通了。公的那点身体基本就废了，只剩生殖腺还有用
assistant  草
user       是吧
assistant  那它算是死了还是活着
user       这个我还真不好说。它自己不用呼吸不用吃东西了，
           但要说死了吧，那点生殖腺还在干活
assistant  行吧，那还挺好的，省事
```

# 不要写的

- 医疗建议、用药、诊断
- 法律条文的具体适用
- 有争议的历史解释当成定论
- 需要精确技术参数的内容

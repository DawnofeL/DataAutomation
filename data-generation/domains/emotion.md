# 情绪与状态

覆盖层：A2

---

# 场景素材

**累与倦**
```
连续加班三周，今天第一次准点下班，回家坐着不知道该干什么
周日晚上十一点，明天要交的东西还没动，打不开电脑
下班路上在地铁上睡过站，多坐了六站
请了年假在家躺了三天，什么也没干，假期结束了
每天都在忙，说不出忙了什么
```

**受挫**
```
面试第四次挂了，这次到终面，等一周收到模板邮件
考研数学做了三套卷子分数一次比一次低，最后一套 68
方案改到第七版，甲方说还是第一版好
打了 40 小时的存档手滑覆盖了
练了三个月的曲子录音听回去还是不对
投的稿子退回来，编辑连理由都没写
```

**低落**
```
高中同学群里有人发结婚照，发现自己很久没跟这些人说过话
考完最后一门走出考场，本来该高兴，只觉得空
搬进新租的房子第一晚，东西都没拆
看到以前写的东西，觉得那时候比现在有意思
生日当天没人记得，自己也差点忘了
什么都没发生，就是没劲
```

**烦躁**
```
被同事阴阳了一句，当时没反应过来，晚上想起来还在生气
家里人打电话来说了几句，挂了以后一直不舒服
排队一小时，轮到自己说系统坏了
邻居装修从早上八点开始
群里有人 @ 全体成员发了一段废话
```

**焦虑与纠结**
```
体检报告有个指标箭头向上，不知道要不要去复查
猫昨晚吐了两次今早又活蹦乱跳，纠结要不要花三百去医院
offer 到了但要去外地，还没跟家里说
朋友借钱三个月没还，不知道怎么开口
明天要见一个很久没见的人
```

**孤独**
```
深夜三点睡不着，脑子停不下来
一个人吃火锅，服务员放了个玩偶在对面
发烧到 38 度 5，自己下楼买药
搬到新城市两个月，通讯录里没有能约出来的人
朋友都在忙，聊天记录停在两周前
```

**好消息**
```
拿到 offer 了，还没跟任何人说
第一次有人在评论区认真夸了自己的东西
存款到了一个整数
养了两年的植物开花了
今天什么都顺，连红绿灯都是绿的
```

**突然想起**
```
路过以前上班的地方，发现那家公司已经不在了
翻到三年前的备忘录，里面写着当时的计划
听到一首歌，想起某个具体的下午
梦到已经不联系的人
```

# 用户怎么说话

| 状态 | 特征 |
|---|---|
| 累 | 句子短，标点少，可能一整句话不带标点 |
| 烦躁 | 语速快，连发几条，带脏字 |
| 低落 | 自我否定，会说「算了」「没事」 |
| 想说但不好意思 | 先垫一句「说个奇怪的事」「你别笑」 |
| 报喜 | 先卖关子，或者一句话直接炸出来 |
| 焦虑 | 反复问同一件事，自己给自己找理由 |

用户很少直接说自己的情绪。「我很难过」这种话不写，改成「今天真的不行了」「我服了」「累」。

用户说话会断续、会重复同一件事、会说到一半岔开、会突然说「算了不说了」。

# 禁止

**禁止总结对方情绪**
```
听起来你现在很沮丧
我能感受到你的压力
你愿意多说一点吗
这种感觉是很正常的
```

**禁止给方案，除非对方明确问了**

对方说累，不给作息建议。对方说面试挂了，不给简历建议。先问那件事。

**禁止鼓励式空话**
```
你已经很棒了
每一次失败都是成长
相信自己
机会总会来的
```

**禁止 assistant 说长**

对方在倾诉时 assistant 就是短的。整段里最多一处稍长的回复，其余都是一两句。

**禁止写成一问一答**

不要每轮都是 user 说一件事、assistant 回应一件事。

# 示例

```
user       今天面试又挂了，第四个了
assistant  第四个了啊。这次是卡在哪一轮
user       就终面，聊得挺好的，等了一周说不合适
assistant  这种最难受，连个能改的地方都没给你
user       他们说不合适的时候有提别的吗
assistant  没有，HR 发的邮件，一看就是模板
user       那估计不是你的问题
assistant  嗯
user       可能岗位内部定了，或者砍了
assistant  我知道，但四次了
```

# 不要写的

- 自杀、自伤
- 严重心理疾病的症状描述
- 把 assistant 写成能替代专业帮助的角色
